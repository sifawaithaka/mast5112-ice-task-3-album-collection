**Introduction**

The Album Collection program is a program designed to record and manage users favorite albums. The program has a form where users input an album name, the artist that created it, the year it was released, music genre it falls under, and personal rating. Users can then view their list of favorite albums as well as delete any entries that they don’t need there anymore. 

**Development Environment**

The program was developed using the following: 

- Expo: tool used to manage and build the project  

- React Native: The framework used to build the mobile app 

- TypeScript: The language used to code the mobile app 

- Institutional VM: The virtual computer provided by Emeris used to code the project 

- BlueStacks 5: The emulator used to run the program 

- Expo Go: The app inside the emulator used to test the program

I tested my program using Expo Go through BlueStacks 5 which served as my emulator.  

When testing my app I used the validation testers I used included: 

- I tested empty fields  

- I tested years that were out of range of the specifications 

- I tested ratings that were out of the range of between 1 to 5
